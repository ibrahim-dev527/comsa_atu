COMSA Website
Developer Documentation

The official website for the Communications Students' Association (COMSA) at Accra Technical University. Built as a fully static HTML/CSS/JavaScript site with a Supabase backend for dynamic content management. The admin panel allows the executives to manage events, blog posts, past questions, and gallery photos without touching any code.

ℹ️
This is a static site — no framework, no build step, no Node.js required. Every page is a self-contained HTML file that can be opened directly in a browser or deployed as-is to any static host.

🗄️ Supabase Configuration

Each page that reads or writes data has these two lines at the top of its <script> block:

const SUPA_URL = 'https://YOUR_PROJECT_ID.supabase.co'; const SUPA_KEY = 'your-anon-public-key-here';

Find these values at: Supabase → Project Settings → API. The anon key is safe to put in frontend code — it cannot write data unless the user is authenticated (enforced by RLS policies).

🔒
Write operations (add, edit, delete) require a valid Supabase Auth JWT. Visitors with only the anon key can only read content — they cannot modify anything.

✏️ How to Update Static Content

  • Change a slider image: Replace the file in images/ with the same filename. Push to GitHub.
  • Change executive name/role/phone: Edit executives.html and contact.html directly.
  • Update history or about text: Edit the text inside about.html.
  • Add a static event card (dept. week): Copy an existing .dw-card block in index.html and edit the content.
  • Add dynamic content (events, posts, PDFs, photos): Log in to admin.html and use the admin panel — no code editing needed.
  • Change social media links: Search for facebook.com/comsa-atu across all files and replace with the correct handles.
  • Change WhatsApp numbers: Search for wa.me/233 across all files.

🔐 Admin Panel

Access the admin panel at /admin.html. Features:

  • Login: Supabase Auth email + password. No passwords stored in code.
  • Overview: Live count of all events, posts, past questions, and gallery photos.
  • Events: Add, edit, delete events. Status (upcoming/past), date, venue, icon, week group.
  • Blog / Posts: Publish news, announcements, flyers. Set featured, add tags, categories.
  • Past Questions: Upload PDF files directly to Supabase Storage. Filter by programme.
  • Gallery: Upload multiple photos at once. Lightbox on the public gallery page.
  • Connection Tester: Setup tab → Run Connection Test — verifies auth, reads, and writes.
  • Mobile sidebar: Hamburger navigation for managing content from a phone.

🚀 Deployment

Deploying to Vercel is a 3-step process:

# 1. Push all files to GitHub git add . git commit -m "COMSA website initial deploy" git push origin main # 2. Go to vercel.com → New Project → Import GitHub repo # 3. Leave all settings default → Deploy # Done! Site is live at your-project.vercel.app

Every subsequent git push to the main branch automatically triggers a new deployment on Vercel.
