Step 2

Logo Setup

🏛️
logo.jpg — Used in 4 places on every page
Navbar · Footer · Chatbot header · Favicon (browser tab icon)
✅
How it works: Simply name your logo file logo.jpg and place it in the images/ folder. It automatically appears in the navbar, footer, chatbot header, and as the browser tab icon on every page. No code changes needed!
1
Prepare your logo
Best size: 200×200px or square (1:1 ratio). PNG with transparent background works — just save as JPG. Minimum 100×100px.
2
Name it exactly: logo.jpg
The filename must be exactly logo.jpg (lowercase). Place it in your images/ folder alongside the HTML files.
3
Done! It appears everywhere automatically
If the logo fails to load for any reason, the site gracefully shows "ATU" text as a fallback — so nothing breaks.

Step 6

Blog & Gallery

📝
Adding Permanent Blog Posts with Flyers
blog.html — use the form at the bottom for quick posts, or edit HTML for permanent ones
1
Quick Posts (Session Only)
Scroll to the Add New Post form at the bottom of blog.html. Fill in the title, category, description, upload a flyer, and click "Publish Post". The post appears instantly — but disappears on page refresh.
2
Permanent Posts (Recommended)
To make a post permanent, open blog.html in your editor. Find the #posts-grid section. Copy an existing .post-c div, paste it, then edit: the image src, data-title, data-cat, data-author, data-date, data-full (full content), and the visible title/description text.
💡
For permanent posts, put your flyer image in images/ (e.g. comsa60.jpg) and set it as the img src inside the post's .post-img div. The image shows in both the card and the read-more popup.
🖼️
Gallery Photos — Two Methods
gallery.html — upload form for quick adds, edit HTML for permanent photos
A
Permanent Photos — Edit the HTML
Open gallery.html. Find the #gal-grid section. Each .gal-item has an img tag — just replace the src with your comsa image filename (e.g. comsa70.jpg). Change data-cat (events/executives/campus/flyers/academic) and data-title for the caption.
B
Quick Upload — Use the Form
Scroll to Upload to Gallery at the bottom of gallery.html. Drag multiple photos, set a caption and category, click Upload. Photos appear instantly — but disappear on page refresh.
Step 7

Admin Password — In Supabase

🔒
The admin password is never stored in any HTML file. It lives in Supabase as a SHA-256 hash. Even if someone sees your source code, they cannot find the password.
🗄️
7a — Create the admin_config table
Run this once in Supabase → SQL Editor
CREATE TABLE IF NOT EXISTS admin_config ( id uuid DEFAULT gen_random_uuid() PRIMARY KEY, password_hash text NOT NULL ); ALTER TABLE admin_config ENABLE ROW LEVEL SECURITY; CREATE POLICY "Allow read admin_config" ON admin_config FOR SELECT USING (true);
🖥️
7b — Generate your SHA-256 hash
Open any browser tab → press F12 → Console tab → paste this
// Replace 'yourPasswordHere' with your real chosen password const hashBuffer = await crypto.subtle.digest('SHA-256', new TextEncoder().encode('yourPasswordHere')); const hash = Array.from(new Uint8Array(hashBuffer)).map(b => b.toString(16).padStart(2, '0')).join(''); console.log(hash); // Copy the long string that appears below
📋
Copy the 64-character hash string that appears in the console. You will paste it in Step 7c. Keep your actual password somewhere safe — you will need it to log in.
💾
7c — Insert the hash into Supabase
Supabase → SQL Editor → paste your hash below
-- Replace with YOUR hash from Step 7b INSERT INTO admin_config (password_hash) VALUES ('paste_your_64_character_hash_here');
✅
Only one row should exist. To change your password later: run DELETE FROM admin_config; then insert the new hash. Done!
Step 8

Deploy to Vercel

🚀
Go Live for Free on Vercel
Pure HTML/CSS/JS — deploys in under 2 minutes, completely free
1
Create a free account at vercel.com
Go to vercel.com and sign up with GitHub or email. It's completely free for static HTML sites — no credit card needed.
2
Click "Add New → Project" → "Upload Folder"
On your Vercel dashboard, click the New Project button, then choose "Upload" and drag your entire comsa/ folder — all HTML files and the images/ folder together.
3
Make sure index.html is at the root
Vercel needs to see index.html directly — not inside a subfolder. If you zipped the folder, make sure the zip doesn't add an extra level.
4
Click Deploy — live in seconds!
Vercel gives you a free URL like comsa-atu.vercel.app. You can also connect a custom domain (e.g. comsa.atu.edu.gh) under Project Settings → Domains.
5
Update the OG tags with your live URL
After you get your live URL, open each HTML file and find og:url in the head — update it with your real URL. This helps when people share your site on WhatsApp and Facebook.
🎉
Alternatives: You can also host on Netlify (netlify.com) or GitHub Pages — same process, all free for static HTML sites.

const POPUP_CONFIG = {

📝 Blog Posts — How They Stay Permanently
Blog posts are stored in the posts table in Supabase. When you publish a post from the Admin Panel:
• It is saved to the database and immediately visible on blog.html
• It stays there permanently until you delete it from the Admin Panel
• No code changes or redeployment needed — just post and it's live
• You can post: text articles, flyer image links, quotes, announcements
• To add a flyer image to a post: upload the image to Supabase Storage (blog-images bucket), copy the public URL, paste it in the Image URL field in Admin → Blog
⚠️ Important: Make sure Supabase is configured (SUPA_URL + SUPA_KEY filled in blog.html and admin.html) before posts will appear.

-- 1. EVENTS TABLE
CREATE TABLE IF NOT EXISTS events (
  id           uuid        DEFAULT gen_random_uuid() PRIMARY KEY,
  title        text        NOT NULL,
  description  text,
  category     text,
  event_date   date        NOT NULL,
  event_time   text,
  venue        text,
  audience     text,
  status       text        DEFAULT 'upcoming',
  icon         text        DEFAULT '🎉',
  image_url    text,
  week_group   text,
  created_at   timestamptz DEFAULT now()
);

-- 2. BLOG POSTS TABLE
CREATE TABLE IF NOT EXISTS posts (
  id           uuid        DEFAULT gen_random_uuid() PRIMARY KEY,
  title        text        NOT NULL,
  excerpt      text,
  content      text,
  category     text        DEFAULT 'news',
  author       text        DEFAULT 'COMSA Secretariat',
  image_url    text,
  is_featured  boolean     DEFAULT false,
  tags         text[],
  created_at   timestamptz DEFAULT now()
);

-- 3. PAST QUESTIONS TABLE
CREATE TABLE IF NOT EXISTS past_questions (
  id            uuid        DEFAULT gen_random_uuid() PRIMARY KEY,
  course_title  text        NOT NULL,
  course_code   text,
  year_sem      text,
  programme     text,
  pdf_url       text,
  storage_path  text,
  created_at    timestamptz DEFAULT now()
);

-- 4. GALLERY PHOTOS TABLE
CREATE TABLE IF NOT EXISTS gallery_photos (
  id            uuid        DEFAULT gen_random_uuid() PRIMARY KEY,
  caption       text,
  image_url     text        NOT NULL,
  storage_path  text,
  created_at    timestamptz DEFAULT now()
);

-- ═══════════════════════════════════════════════════════
-- ROW LEVEL SECURITY
-- ═══════════════════════════════════════════════════════
ALTER TABLE events         ENABLE ROW LEVEL SECURITY;
ALTER TABLE posts          ENABLE ROW LEVEL SECURITY;
ALTER TABLE past_questions ENABLE ROW LEVEL SECURITY;
ALTER TABLE gallery_photos ENABLE ROW LEVEL SECURITY;

-- PUBLIC READ (anyone can view)
CREATE POLICY "Public read events"         ON events         FOR SELECT USING (true);
CREATE POLICY "Public read posts"          ON posts          FOR SELECT USING (true);
CREATE POLICY "Public read past_questions" ON past_questions FOR SELECT USING (true);
CREATE POLICY "Public read gallery_photos" ON gallery_photos FOR SELECT USING (true);

-- ADMIN WRITE (admin.html is the security layer — keep admin URL private)
CREATE POLICY "Admin write events"         ON events         FOR ALL USING (true) WITH CHECK (true);
CREATE POLICY "Admin write posts"          ON posts          FOR ALL USING (true) WITH CHECK (true);
CREATE POLICY "Admin write past_questions" ON past_questions FOR ALL USING (true) WITH CHECK (true);
CREATE POLICY "Admin write gallery_photos" ON gallery_photos FOR ALL USING (true) WITH CHECK (true);

-- ═══════════════════════════════════════════════════════
-- STORAGE BUCKETS
-- ═══════════════════════════════════════════════════════
INSERT INTO storage.buckets (id, name, public) VALUES
  ('past-questions', 'past-questions', true),
  ('blog-images',    'blog-images',    true),
  ('gallery',        'gallery',        true)
ON CONFLICT DO NOTHING;

-- Public read all 3 buckets
CREATE POLICY "Public read storage"
  ON storage.objects FOR SELECT
  USING (bucket_id IN ('past-questions', 'blog-images', 'gallery'));

-- Admin upload
CREATE POLICY "Admin upload storage"
  ON storage.objects FOR INSERT WITH CHECK (true);

-- Admin delete
CREATE POLICY "Admin delete storage"
  ON storage.objects FOR DELETE USING (true);
