Step 2

The Welcome Popup

The popup appears automatically when a user visits the site for the first time. It shows your latest news or flyer. It will NOT appear again until they clear their browser session.

📢
Editing the Popup
Open index.html and find the POPUP CONFIG section in the JavaScript
1
Open index.html in your code editor
Use VS Code, Notepad++, or any text editor. Press Ctrl+F and search for POPUP CONFIG — you'll find it immediately.
2
Edit the POPUP object
Change the values below to your own content:
/* ===== POPUP CONFIG — EDIT THESE ===== */
const POPUP = {
  active: true, // false = disable popup
  badge: '📢 Latest News', // Small label at top
  title: 'Your Popup Headline', // Main heading
  message: 'Your popup message goes here...', // Body text
  image: 'images/popup-flyer.jpg', // 📸 Your flyer image
  btnText: 'Learn More →', // Button text
  btnLink: 'events.html', // Button destination
};
💡
To upload a flyer to the popup, save your image inside the images/ folder and set image: 'images/your-flyer.jpg'. The image will appear at the top of the popup. Leave it empty (image: '') for text-only.
✅
To turn off the popup completely, set active: false. To reset it so it shows again (for testing), open your browser console and type: sessionStorage.removeItem('comsa-popup') then refresh.
Step 3

Hero Slider Backgrounds

Every page has a swipeable hero slider. By default they show coloured gradients. To add real photos, open the page and find the slide CSS classes.

🖼️
Adding Background Photos to Slides
Do this for every page — index, about, executives, events, blog, gallery, contact
1
Save your photos in the images/ folder
Use wide/landscape photos. Minimum size: 1400×600px. Good sources: your events, campus photos, group shots.
2
Open any HTML file and find the slide CSS
In the <style> block near the top of the file, search for .ph-s1 (for page heroes) or .slide-1 (for the home hero).
3
Add your image to each slide class
/* Home page hero slides — in index.html */
.slide-1 {
  background: linear-gradient(...); /* keep as fallback */
  background-image: url('images/hero-slide-1.jpg');
  background-size: cover;
  background-position: center;
}

/* Other page hero slides (about, events etc.) */
.ph-s1 {
  background-image: url('images/about-hero.jpg');
  background-size: cover;
  background-position: center;
}
ℹ️
The dark overlay on top of the slides is automatic — so even bright photos will look good. If you want the photo brighter, find .ph-overlay or .slide-overlay in the CSS and reduce the opacity value.

Step 5

Executives & Lecturers

👔
Adding Executive Photos
executives.html — each flip card has a 📸 comment showing exactly where to put the image

Inside each exec flip card, find the commented image tag. Copy and paste the img tag shown in the comment and fill in your src:


<img src="images/president.jpg"
     style="position:absolute;inset:0;width:100%;height:100%;object-fit:cover;object-position:top;z-index:2">
💡
Use object-position: top so the face always shows even when the circle crops the photo. For best results crop photos to square (1:1 ratio) before uploading.
🎓
Updating Lecturer Details
executives.html — scroll to the Lecturers section near the bottom
1
Find the Lecturers section in executives.html
Search for id="lecturers" in executives.html. You'll see 6 lecturer cards ready to fill in.
2
Edit each lecturer card
Update the Name, Title (e.g. Senior Lecturer), Bio (short description), Specialisation tags, and Email.
3
Add more lecturers
To add a new lecturer, copy one entire .lec-c div block and paste it inside .lec-grid. Edit the details and add the photo.
4
Add lecturer photos
Inside each .lec-av div, add your img tag (same format as executives above) with src="images/lec1.jpg"
Step 6

Using the Blog

📝
Adding Blog Posts with Flyers
blog.html — use the Add Post form at the bottom of the page
📸
Upload Flyers
The Add Post form has a drag-and-drop image upload. Your flyer appears at the top of the post card and in the read-more popup.
✍️
Write Content
Write your full post text in the content area. Use line breaks to separate paragraphs — they format automatically.
🏷️
Categories
Choose from: News, Flyer, Event, Academic, or Social. Posts can be filtered by category instantly.
⚠️
Important: Posts added through the form are temporary — they disappear on page refresh. To make posts permanent, copy a .post-c block in blog.html and paste it inside #posts-grid with your content. See the existing post blocks as examples.
ℹ️
To add a permanent flyer post with a real image: find the HTML post block, locate the .post-img div inside it, and add: <img src="images/your-flyer.jpg" alt="Post Title" style="position:absolute;inset:0;width:100%;height:100%;object-fit:cover">
Step 7

Setting Up the Gallery

🖼️
Two Ways to Add Gallery Photos
gallery.html — use the upload form OR edit the HTML directly

Option A — Permanent Photos (Recommended):

1
Find an existing .gal-item in gallery.html
Open gallery.html and look for the masonry grid section. Each .gal-item div is one photo.
2
Add your image to the .gal-real-img tag
Inside each item, find <img ... class="gal-real-img"/> and set the src to your image path.
3
Copy the block to add more photos
To add a new photo, copy a complete .gal-item div and paste it inside .gal-grid. Change the src, title, and data-cat.
<!-- Add your photo like this -->
<div class="gal-item" data-cat="events" data-title="Your Caption">
  <div class="gal-placeholder" style="height:260px">
    <img src="images/your-photo.jpg" class="gal-real-img" alt="Caption"/>
  </div>
  <div class="gal-overlay">...</div>
</div>

Option B — Use the Upload Form (Temporary):

Scroll to the bottom of gallery.html and use the Upload to Gallery form. Drag multiple photos, add a caption and category, click upload. Photos appear instantly — but only for that browser session.

Website Features
🌙
Dark / Light Mode
Toggle in navbar and mobile menu. Preference saved in localStorage across pages.
⏳
3-Second Loader
Animated COMSA loading screen on first visit. Shows once per session using sessionStorage.
📢
First-Visit Popup
News/flyer popup shows only on first visit. Supports image flyers and custom messages.
🖼️
Hero Slider
Auto-advancing, swipeable on mobile, dot navigation. All pages have their own slider.
🔄
Flip Cards
Executive cards flip on hover to show contact info — phone and WhatsApp links.
🔍
Lightbox Gallery
Click any photo to open full-size with left/right arrows and keyboard support.
📂
Blog with Upload
Add posts with flyer images, categories, and full content. Read-more popup on click.
📤
Gallery Upload
Bulk upload up to 10 photos at once with category tags. Appear in masonry grid instantly.
✨
Scroll Animations
Elements fade and slide in as you scroll using IntersectionObserver for smooth performance.
Step 9 — Optional

Deploying to Vercel

🚀
Go Live for Free on Vercel
No backend, no server — pure HTML/CSS/JS deploys instantly
1
Create a free account at vercel.com
Sign up with GitHub or email at vercel.com. It's completely free for static sites.
2
Click "Add New → Project" and choose "Upload Folder"
Drag and drop your entire comsa/ folder — all HTML files, the images/ folder, everything.
3
Set the Root Directory to your folder
Make sure index.html is at the root of what you upload — not inside a subfolder.
4
Click Deploy — your site is live!
Vercel gives you a free URL like comsa-atu.vercel.app. You can also connect a custom domain.
🎉
Alternative: You can also host on Netlify (netlify.com) or GitHub Pages — same process. All three are free for static HTML sites.
