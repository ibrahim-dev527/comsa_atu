Step 2

Logo Setup

🏛️
logo.jpg — Used in 4 places on every page
Navbar · Footer · Chatbot header · Favicon (browser tab icon)
✅
How it works: Simply name your logo file logo.jpg and place it in the images/ folder. It automatically appears in the navbar, footer, chatbot header, and as the browser tab icon on every page. No code changes needed!
1
Prepare your logo
Best size: 200×200px or square (1:1 ratio). PNG with transparent background works — just save as JPG. Minimum 100×100px.
2
Name it exactly: logo.jpg
The filename must be exactly logo.jpg (lowercase). Place it in your images/ folder alongside the HTML files.
3
Done! It appears everywhere automatically
If the logo fails to load for any reason, the site gracefully shows "ATU" text as a fallback — so nothing breaks.

Step 4

The Welcome Popup

📢
Editing the Popup Announcement
Open index.html — search for POPUP_CONFIG in the JavaScript at the bottom
/* ===== POPUP CONFIG — Edit these values ===== */ const POPUP_CONFIG = { active: true, // Set false to disable popup badge: '📢 Welcome to COMSA!', title: 'Your Popup Headline Here', message: 'Your announcement text goes here...', image: '', // 📸 To show flyer: 'images/comsa41.jpg' btnText: 'Explore COMSA →', btnLink: 'about.html', // Where the button goes };
💡
To add a flyer image to the popup, put your flyer in the images/ folder and set: image: 'images/your-flyer.jpg'. Portrait orientation works best. Leave image: '' for text-only popup.
✅
The popup shows once per browser session. To test it again, open browser console (F12) and type: sessionStorage.removeItem('comsa-popup') then refresh the page.

Step 6

Blog & Gallery

📝
Adding Permanent Blog Posts with Flyers
blog.html — use the form at the bottom for quick posts, or edit HTML for permanent ones
1
Quick Posts (Session Only)
Scroll to the Add New Post form at the bottom of blog.html. Fill in the title, category, description, upload a flyer, and click "Publish Post". The post appears instantly — but disappears on page refresh.
2
Permanent Posts (Recommended)
To make a post permanent, open blog.html in your editor. Find the #posts-grid section. Copy an existing .post-c div, paste it, then edit: the image src, data-title, data-cat, data-author, data-date, data-full (full content), and the visible title/description text.
💡
For permanent posts, put your flyer image in images/ (e.g. comsa60.jpg) and set it as the img src inside the post's .post-img div. The image shows in both the card and the read-more popup.
🖼️
Gallery Photos — Two Methods
gallery.html — upload form for quick adds, edit HTML for permanent photos
A
Permanent Photos — Edit the HTML
Open gallery.html. Find the #gal-grid section. Each .gal-item has an img tag — just replace the src with your comsa image filename (e.g. comsa70.jpg). Change data-cat (events/executives/campus/flyers/academic) and data-title for the caption.
B
Quick Upload — Use the Form
Scroll to Upload to Gallery at the bottom of gallery.html. Drag multiple photos, set a caption and category, click Upload. Photos appear instantly — but disappear on page refresh.
Step 7

Deploy to Vercel

🚀
Go Live for Free on Vercel
Pure HTML/CSS/JS — deploys in under 2 minutes, completely free
1
Create a free account at vercel.com
Go to vercel.com and sign up with GitHub or email. It's completely free for static HTML sites — no credit card needed.
2
Click "Add New → Project" → "Upload Folder"
On your Vercel dashboard, click the New Project button, then choose "Upload" and drag your entire comsa/ folder — all HTML files and the images/ folder together.
3
Make sure index.html is at the root
Vercel needs to see index.html directly — not inside a subfolder. If you zipped the folder, make sure the zip doesn't add an extra level.
4
Click Deploy — live in seconds!
Vercel gives you a free URL like comsa-atu.vercel.app. You can also connect a custom domain (e.g. comsa.atu.edu.gh) under Project Settings → Domains.
5
Update the OG tags with your live URL
After you get your live URL, open each HTML file and find og:url in the head — update it with your real URL. This helps when people share your site on WhatsApp and Facebook.
🎉
Alternatives: You can also host on Netlify (netlify.com) or GitHub Pages — same process, all free for static HTML sites.
