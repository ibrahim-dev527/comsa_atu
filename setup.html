Complete Setup Guide

Follow these steps in order to go from a fresh Supabase project to a fully working COMSA website in under 15 minutes.

Go to Admin Panel View README
1

Get Your Supabase Keys

Every HTML file needs your Supabase Project URL and Anon Key. These connect the website to your database.

1
Go to supabase.com and sign in to your account.
2
Click your comsa-atu project to open it.
3
In the left sidebar click Project Settings (gear icon at the bottom).
4
Click API. Copy two values: Project URL and anon / public key.
5
Open each HTML file below and find these two lines near the top of the <script> tag. Replace the placeholders with your real values.
const SUPA_URL = 'https://YOUR_PROJECT_ID.supabase.co'; const SUPA_KEY = 'your-anon-public-key-here';
📄
Update this in ALL of these files: index.html, about.html, executives.html, events.html, blog.html, gallery.html, past-questions.html, contact.html, admin.html
2

Run the Complete SQL

This single SQL script creates all tables, enables row-level security, sets read/write policies, and creates the storage buckets. Run it once on a fresh project.

⚠️
If you already have old tables from a previous attempt, run DROP TABLE IF EXISTS events, posts, past_questions, gallery_photos CASCADE; first to start clean.
-- ═══════════════════════════════════════ -- COMSA WEBSITE — COMPLETE DATABASE SETUP -- Run in Supabase → SQL Editor → New Query -- ═══════════════════════════════════════ -- 1. DROP OLD TABLES (clean slate) DROP TABLE IF EXISTS gallery_photos CASCADE; DROP TABLE IF EXISTS past_questions CASCADE; DROP TABLE IF EXISTS posts CASCADE; DROP TABLE IF EXISTS events CASCADE; -- 2. CREATE TABLES CREATE TABLE events ( id uuid DEFAULT gen_random_uuid() PRIMARY KEY, title text NOT NULL, description text, category text, event_date date NOT NULL, event_time text, venue text, audience text, status text DEFAULT 'upcoming', icon text DEFAULT '🎉', image_url text, week_group text, created_at timestamptz DEFAULT now() ); CREATE TABLE posts ( id uuid DEFAULT gen_random_uuid() PRIMARY KEY, title text NOT NULL, excerpt text, content text, category text DEFAULT 'news', author text DEFAULT 'COMSA Secretariat', image_url text, is_featured boolean DEFAULT false, tags text[], created_at timestamptz DEFAULT now() ); CREATE TABLE past_questions ( id uuid DEFAULT gen_random_uuid() PRIMARY KEY, course_title text NOT NULL, course_code text, year_sem text, programme text, pdf_url text, storage_path text, created_at timestamptz DEFAULT now() ); CREATE TABLE gallery_photos ( id uuid DEFAULT gen_random_uuid() PRIMARY KEY, caption text, image_url text, storage_path text, created_at timestamptz DEFAULT now() ); -- 3. ENABLE ROW LEVEL SECURITY ALTER TABLE events ENABLE ROW LEVEL SECURITY; ALTER TABLE posts ENABLE ROW LEVEL SECURITY; ALTER TABLE past_questions ENABLE ROW LEVEL SECURITY; ALTER TABLE gallery_photos ENABLE ROW LEVEL SECURITY; -- 4. PUBLIC READ POLICIES (anyone can view content) CREATE POLICY "Public read events" ON events FOR SELECT USING (true); CREATE POLICY "Public read posts" ON posts FOR SELECT USING (true); CREATE POLICY "Public read past_questions" ON past_questions FOR SELECT USING (true); CREATE POLICY "Public read gallery_photos" ON gallery_photos FOR SELECT USING (true); -- 5. AUTH WRITE POLICIES (only your logged-in admin can add/edit/delete) CREATE POLICY "Auth write events" ON events FOR ALL USING (auth.uid() IS NOT NULL) WITH CHECK (auth.uid() IS NOT NULL); CREATE POLICY "Auth write posts" ON posts FOR ALL USING (auth.uid() IS NOT NULL) WITH CHECK (auth.uid() IS NOT NULL); CREATE POLICY "Auth write past_questions" ON past_questions FOR ALL USING (auth.uid() IS NOT NULL) WITH CHECK (auth.uid() IS NOT NULL); CREATE POLICY "Auth write gallery_photos" ON gallery_photos FOR ALL USING (auth.uid() IS NOT NULL) WITH CHECK (auth.uid() IS NOT NULL); -- 6. STORAGE BUCKETS INSERT INTO storage.buckets (id, name, public, file_size_limit, allowed_mime_types) VALUES ('gallery', 'gallery', true, 10485760, ARRAY['image/jpeg','image/jpg','image/png','image/webp','image/gif']) ON CONFLICT (id) DO UPDATE SET public=true; INSERT INTO storage.buckets (id, name, public, file_size_limit, allowed_mime_types) VALUES ('past-questions', 'past-questions', true, 20971520, ARRAY['application/pdf']) ON CONFLICT (id) DO UPDATE SET public=true; -- 7. STORAGE POLICIES DROP POLICY IF EXISTS "Public read gallery" ON storage.objects; DROP POLICY IF EXISTS "Auth upload gallery" ON storage.objects; DROP POLICY IF EXISTS "Auth delete gallery" ON storage.objects; DROP POLICY IF EXISTS "Public read pq" ON storage.objects; DROP POLICY IF EXISTS "Auth upload pq" ON storage.objects; DROP POLICY IF EXISTS "Auth delete pq" ON storage.objects; CREATE POLICY "Public read gallery" ON storage.objects FOR SELECT USING (bucket_id='gallery'); CREATE POLICY "Auth upload gallery" ON storage.objects FOR INSERT WITH CHECK (bucket_id='gallery' AND auth.uid() IS NOT NULL); CREATE POLICY "Auth delete gallery" ON storage.objects FOR DELETE USING (bucket_id='gallery' AND auth.uid() IS NOT NULL); CREATE POLICY "Public read pq" ON storage.objects FOR SELECT USING (bucket_id='past-questions'); CREATE POLICY "Auth upload pq" ON storage.objects FOR INSERT WITH CHECK (bucket_id='past-questions' AND auth.uid() IS NOT NULL); CREATE POLICY "Auth delete pq" ON storage.objects FOR DELETE USING (bucket_id='past-questions' AND auth.uid() IS NOT NULL); -- 8. VERIFY (run this to confirm setup) SELECT table_name FROM information_schema.tables WHERE table_schema='public' AND table_type='BASE TABLE'; SELECT tablename, policyname, cmd FROM pg_policies WHERE schemaname='public'; SELECT id, name, public FROM storage.buckets;
✅
After running, the verification at the bottom should show 4 tables, 8 table policies, and 2 storage buckets.
3

Create Your Admin Account

Your admin login uses Supabase Authentication. No passwords are stored in any code file — Supabase handles everything securely.

1
In your Supabase project, click Authentication in the left sidebar.
2
Click Settings → Email → turn OFF "Enable email confirmations" so you can log in immediately.
3
Click Users in the Authentication sub-menu.
4
Click Add user → Create new user. Enter your admin email and a strong password. Click Create User.
5
Go to admin.html on your deployed site. Enter the email and password you just created. Click Sign In.
💡
Your password is managed entirely by Supabase. To reset it, go to Supabase → Authentication → Users → click your user → Send password recovery. No code changes needed.
4

Configure Storage (for uploads)

The SQL in Step 2 creates the buckets automatically. If photo or PDF uploads fail, verify these settings manually.

1
Go to Supabase → Storage. You should see two buckets: gallery and past-questions.
2
Click each bucket → Edit → confirm Public bucket is checked.
3
If uploads still fail after deploying, go to Storage → Policies and confirm the INSERT and DELETE policies exist for both buckets.
5

Deploy to Vercel

COMSA is a static site — just HTML, CSS, and JavaScript files. No build step required.

1
Upload all your HTML files and the images/ folder to a GitHub repository.
2
Go to vercel.com → New Project → Import your GitHub repo.
3
Leave all build settings as default (no framework, no build command). Click Deploy.
4
Your site goes live at your-project.vercel.app. Every push to GitHub auto-redeploys.
💡
Make sure ALL your HTML files have the correct SUPA_URL and SUPA_KEY filled in before pushing to GitHub.

Frequently Asked Questions

Why is data not showing on the live website?
Make sure you filled in SUPA_URL and SUPA_KEY in each page file. Then go to Admin → Setup → Run Connection Test. If reads fail, check your public RLS policies are correctly set.
Why do writes fail ("Error saving") in the admin?
You must be logged in with a valid Supabase Auth account. The JWT token is stored in sessionStorage — if you refresh or open a new tab, log in again. Run the Connection Test to verify your write access.
How do I change my admin password?
Go to Supabase → Authentication → Users → click your user → Send password recovery or reset directly. No code changes needed.
Why do image/PDF uploads fail?
Confirm you are logged in to the admin (uploads require auth). Then go to Supabase → Storage → confirm both buckets are public and the INSERT policies exist. File sizes must be under 10MB (images) and 20MB (PDFs).
How do I add a new executive next year?
Update the executive photos in the images/ folder and edit the names/roles in executives.html. Push to GitHub and Vercel redeploys automatically.
